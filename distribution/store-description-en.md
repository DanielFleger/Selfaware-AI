# Selfaware AI / SamurAI

SamurAI autonomously controls selected AI slots: economy, recruitment and combat.
No LLM subscription or supervising assistant is required. The separate application
records measured combat/movement values and match observations for later decisions.
The project name does not imply consciousness, autonomous source-code rewriting
or a demonstrated general improvement in playing strength.

## Setup

1. Install Selfaware AI from the Store and activate it under Content.
2. Set up the separate Selfaware application once for the same game directory.
3. Start through **Selfaware AI (lokal)** and select SamurAI in a custom skirmish.

The external application is required: a Store module must neither extract nor
start it. Downloads/source: [Selfaware AI](https://github.com/UnofficialCrusaderPatch/Selfaware-AI/releases).
Learning state and startup logs are stored under Documents/Selfaware AI.

SamurAI occupies the Abbot slot; other configured opponents remain available.
Customisations controls its starting troops; the proposed preset is 4 assassins
and 6 Arabian archers. Changes apply to fresh skirmishes after restarting the game.
Requires 64-bit Windows, Crusader 1.41 and UCP 3.0.7.

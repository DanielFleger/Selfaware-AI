# Preserved design plans

The `Plan*` files in this directory are the original design proposals, with
their contents and dates preserved. They describe both historical goals and
unimplemented work; they are not a record of completed functionality.

Use [ARCHITECTURE.md](../ARCHITECTURE.md), [ORGANIZATION.md](../ORGANIZATION.md)
and [BACKLOG.md](../BACKLOG.md) for the current implementation and next steps.
Old paths translate through [relocations.json](../relocations.json).
